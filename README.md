# AI-Driven KYC Automated System for Risk Mitigation in Nigerian Financial Institutions

## Overview

This repository contains the implementation of a Professional Master's Project submitted in partial fulfilment of the requirements for the award of the Master of Information Technology (MIT) degree.

The project focuses on the design and implementation of an AI-driven Know Your Customer (KYC) automation system that assists financial institutions in improving customer onboarding efficiency, reducing manual verification processes, and supporting risk mitigation through intelligent workflow automation.

---

## Project Objectives

The project aims to:

1. Design and implement a web-based KYC automation system.
2. Automate identity document processing using Optical Character Recognition (OCR).
3. Implement a rule-based risk assessment engine for customer risk classification.
4. Improve customer onboarding workflow through process automation.
5. Provide administrative review and decision support capabilities.
6. Maintain audit logs for compliance and accountability.

---

## Engineering Principles

The project will use modern JavaScript and modern Node.js features by default, including ES Modules, native environment variable support, and native file watching, while minimizing unnecessary dependencies.

- Modern JavaScript (ES Modules)
- Native Node.js features where available
- Minimal external dependencies
- Security-first design
- Layered architecture
- API versioning
